
# OOP Practical 1

## GitHub Setup and C++ Fundamentals

### Aim
To practise basic C++ syntax and learn how to track code changes using Git and GitHub.

### Concepts Demonstrated
- Data types
- Variables and constants
- Arithmetic operators
- Relational operators
- Logical operators
- Input using cin
- Output using cout

### Program File
practical01.cpp

### Compile Command
g++ practical01.cpp -o practical01

### Run Command
.\practical01.exe

### Sample Input
Name: Satinder
Age: 19
First number: 10
Second number: 5

### Sample Output
Sum: 15
Difference: 5
Product: 50
Division: 2

### Result
Successfully created and executed a C++ program demonstrating basic programming concepts and uploaded it to GitHub.
